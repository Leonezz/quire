# Quire 布局重设计（2026-09-19）

目标：简洁、专注、零学习成本。用户打开窗口就知道去哪、按什么。

## 调研：同类产品怎么排

| 产品 | 结构 | 值得借鉴 | 不借鉴 |
|---|---|---|---|
| Apple Mail / Notes | 一条贯穿窗口的工具栏 + 侧栏 · 列表 · 内容三栏，平铺无卡片，1px 分隔 | 统一工具栏；红绿灯落在侧栏顶部，收起侧栏后工具栏自然向左延伸；筛选放侧栏（邮箱 / 文件夹），列表只剩搜索 + 排序 | — |
| Reeder 5 | 侧栏列出每个订阅（带未读数），列表极简，阅读区几乎无 chrome | 来源直接在侧栏可点，选中即筛选；阅读区只留一排图标 | 三栏都是浮动卡片时的视觉噪音 |
| NetNewsWire | 标准三栏，主题化极少 | 键盘优先、少即是多 | — |
| Readwise Reader | 侧栏是"库的切面"（Inbox / Later / Archive / 标签 / 类型），右侧面板承载 Info / Notes，面板由工具栏图标切换 | 切面在侧栏、面板由一处切换、标签作为切面 | 过多 AI 按钮 |
| Zotero 7 | 集合树在侧栏；条目面板用一列竖排图标（Info / Abstract / Notes / Tags / Related）切换分区，工具栏不重复这些入口 | 元数据分区只有一个开关 | 密集的多列表格 |
| Craft / Things | 单一平面、留白、一个主操作 | 让"当前要做的一件事"最亮 | — |

结论：三栏平铺（侧栏 · 列表 · 内容），一条工具栏；**筛选进侧栏，列表只留搜索；面板开关只在工具栏**。

## 现状的问题

1. 三栏是三块带缝隙的玻璃卡片，工具栏也是卡片；侧栏收起后红绿灯旁留出一块空白（卡片不能延伸到红绿灯下面）。
2. Library 列顶部堆了搜索框 + 类型分段 + Type / Tag / Sort 三个菜单，320px 宽时放不下。
3. 阅读器工具栏有 Info / Notes / Contents / Aa / Ask，检查器上又有 Info / Notes / Agent 三个 tab，一件事两个入口。
4. Sources 视图与 Inbox 的"按来源分组"是两处做同一件事（看某个来源的内容）。

### 规则

- **平铺**。窗口就是一个平面：侧栏用系统 vibrancy，列表列与内容区 `bg-content`，三者之间各一条 1px 分隔线（可拖拽）。没有卡片、没有缝隙、没有阴影。
- **一条工具栏**贯穿列表列与内容区，52px，随 titlebar 拖拽。红绿灯落在侧栏顶部；侧栏收起时工具栏向左延伸并留出系统要求的 80px 内缩（这是 macOS 所有应用的做法，不是空白）。工具栏分两段：列表段 = 当前视图标题 + 计数（Library 时加搜索框）；内容段 = 打开的材料标题 + 出处，右侧一排图标。
- **切面在侧栏**。Inbox / Queue / Agent 是三个动作区；Library 下 All / Articles / Papers / Artifacts 是类型切面；Tags 列出前 8 个标签（更多在 "All tags…"）；Sources 逐个列出订阅（健康点 + 未读数），点一个就是"这个来源的 Inbox"；"Manage…" 才进入来源管理（同步 / 暂停 / 断开）。Settings 固定在侧栏底部。
- **列表只做列表**。顶部只有（Library）搜索框，右上角一个排序菜单（Newest / Oldest / Title）；Inbox 按天分组，其余不分组；行 = 标题、来源 · 时间、摘要一行、时长、标签 chips。多选 + 底部一条操作栏（Delete / Copy BibTeX）只在有选中时出现。
- **面板一个开关**。阅读器工具栏右侧：目录（t）、Info（i）、Notes（n）、Aa、Ask（⌘J）；Info / Notes / Ask 三者是互斥的开关，按下即在右侧打开对应面板，面板顶部只有名称和 ×，没有 tab 条。Esc 关闭面板。
- **内容区空态**只有一句话（"Select something to read."），不画卡片。
- **动效**：面板滑入 160ms，列表选择无动画，阅读器切换 120ms 淡入；`prefers-reduced-motion` 全部关闭。
- **键盘**不变：↑↓ 选、↵ 读、q / e / k 决定、⌘N 添加、⌘K 搜索、⌘J Ask、⌘⇧J Agent、⌘, 设置、⌘\ 侧栏、t / i / n 面板。

### 取舍

- 放弃玻璃卡片。它好看但代价是缝隙、阴影和"卡片里再放卡片"的层级；平铺后信息密度更高、焦点更清楚。
- Inbox 的 Date / Source 分段去掉：按来源看就点侧栏里的来源。
- Sources 视图保留但降级为"管理"，从侧栏底部进入。
- 过滤栏整体删除；类型 / 标签切面在侧栏，排序在列表右上角。
